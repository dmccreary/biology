# Standard Deviation Demo Prompt

!!! prompt
    Use the /microsim-generator with the chartjs guide to create a diagram that will demonstrate the
    standard deviation concept.  The user will have a button in the lower left that has the label
    "Regenerate Data".  A slider will control the amount of standard deviation the data has.  Below the
    slide will be the label on the left "Low Standard Deviation" and the right "High Standard Deviation".
    The width of 1 standard deviation will be shown on the chart.  The Y-axis will be "Count of Readings"
    and the horizontal X-axis will be "Experimental Value".
